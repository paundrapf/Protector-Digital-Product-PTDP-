🚀 BUILD INSTRUCTIONS:

CRITICAL: Must be built on Windows machine!

Prerequisites:
1. Windows 10/11 (64-bit)
2. Python 3.8+ 
3. PyInstaller
4. Inno Setup 6.x

Quick Build:
$ python build_windows_installer.py

Output:
→ installer_output/PTDP-Setup-v2.0.exe (~35 MB)
→ dist/windows/PTDP-Creator.exe (~32 MB)
→ dist/windows/PTDP-Viewer.exe (~33 MB)
