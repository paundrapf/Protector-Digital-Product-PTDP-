# 🚀 PTDP - Super Simple User Guide

## For End Users (Reading Protected PDFs)

### Step 1: Download
- Go to website
- Click "Download Viewer.exe"
- Save to your computer

### Step 2: Run
- Find PTDP-Viewer.exe in Downloads folder
- **Double-click** to run
- **NO installation needed!**

### Step 3: Open Protected PDF
1. Click "Open File" or drag & drop .ptdp file
2. Enter the license key (given by seller)
3. Click "Unlock"
4. Read your PDF!

Windows may show: "Windows protected your PC"

**This is normal!** Here's what to do:
1. Click "More info"
2. Click "Run anyway"

Why? Windows warns about new software. PTDP is safe!

## 🆘 Need Help?

### Error: "File not found"
- Make sure .ptdp file exists
- Check file isn't corrupted

### Error: "Invalid license"
- Check you typed the key correctly (copy-paste is safer)
- Contact the seller for correct key
- Make sure license hasn't expired

### Error: "Can't open file"
- Make sure it's a .ptdp file (not regular PDF)
- Try downloading the file again

### App won't start?
- Make sure you're on Windows 10/11 64-bit
- Check antivirus isn't blocking it
- Download fresh copy of .exe
