## 🌊 WHAT IS PTDP?

**PTDP (Protected Digital Product)** isn't just a file format. It's a **vault** for your premium content.
We wrap your PDFs, E-books, and Templates in a secure `.ptdp` container that demands a valid license key to open.

## 🚀 QUICK START

### FOR CREATORS (SELLERS)
1.  **Install**: `pip install -r requirements.txt`
2.  **Create**: Run `python creator.py`
3.  **Protect**: Select your file -> Generate `.ptdp` + License Key.
4.  **Sell**: Send the `.ptdp` file and Key to your buyer.

### FOR USERS (BUYERS)
1.  **Download**: Get the **PTDP Viewer**.
2.  **Open**: Drag & Drop your `.ptdp` file.
3.  **Unlock**: Enter your License Key.
4.  **Enjoy**: Access your premium content securely.

## 📦 INSTALLATION

```bash
# Clone the repo
git clone https://github.com/paundrapf/Protector-Digital-Product-PTDP-.git

# Enter directory
cd Protector-Digital-Product-PTDP-

# Install dependencies
pip install -r requirements.txt

# Run the Viewer
python viewer.py
```
