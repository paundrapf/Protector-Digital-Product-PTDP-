=================

-------------
core/creator.py
  - PTDPCreator class
  - File encryption (AES-256)
  - Metadata embedding
  - Batch protection
  - CLI interface

core/reader.py
  - PTDPReader class
  - File decryption
  - License validation
  - Usage tracking
  - Integrity checking

core/license.py
  - LicenseValidator class

USAGE PATTERNS
==============

FOR SELLERS:
1. Run gui/creator.py or use core/creator.py
2. Protect your digital products
3. Generate licenses with core/license.py
4. Distribute .ptdp files + license keys

FOR BUYERS:
1. Download PTDP Viewer
2. Open .ptdp file
3. Enter license key
4. View protected content

FOR DEVELOPERS:
1. Read docs/DEVELOPER_GUIDE.md
2. Customize config.py
3. Deploy server/api.py (optional)
4. Build with build.py
