🚀 QUICK START (5 MINUTES):
============================

Step 1: Install Dependencies
-----------------------------
cd ptdp-protection
pip install -r requirements.txt


Step 2: Test the System
------------------------
python example_usage.py

This will:
- Protect a sample file
- Generate a license key
- Decrypt and open the file
- Show you how everything works


Step 3: Protect Your First Product
-----------------------------------
Option A - Using GUI (Easiest):
    python gui/creator.py

Option B - Using Python:
    from core.creator import PTDPCreator
    
    creator = PTDPCreator()
    creator.create_protected_file(
        input_file='mybook.pdf',
        output_file='mybook.ptdp',
        config={
            'product_id': 'BOOK001',
            'product_name': 'My Amazing Book',
            'master_password': 'YourSecretPassword123',
            'max_devices': 1
        }
    )


Step 4: Generate License for Buyer
-----------------------------------
Option A - Using GUI:
    Run gui/creator.py, it has built-in license generator

Option B - Using Python:
    from core.license import LicenseValidator
    
    license = LicenseValidator.generate_license(
        product_id='BOOK001',
        hwid=None,  # Any device (or use buyer's device ID)
        expiry_date='LIFETIME'
    )
    
    print(f"License: {license}")


Step 5: Build Executables (Optional)
-------------------------------------
python build.py

This creates:
- PTDP-Viewer.exe → Distribute to buyers
- PTDP-Creator.exe → Keep for yourself

⚠️  IMPORTANT SECURITY NOTES:
==============================

1. Master Password:
   - Keep it SECRET!
   - Different password per product (recommended)
   - Use password manager

2. Secret Key:
   - Change SECRET_KEY in config.py
   - Same key must be used for generation & validation

3. License Keys:
   - One license per buyer
   - Don't share publicly
   - Use device-locked for high-value products
